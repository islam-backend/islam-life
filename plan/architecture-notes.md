## Tasks vs Logs — الفرق الجوهري

### Tasks Collection (موجودة وتمام)
- حاجة لازم **تتعمل** بين تاريخ وتاريخ
- ليها status: `todo` / `doing` / `done`
- بتتمتد على فترة زمنية
- مناسبة لـ: الشغل، المشاريع، الأهداف

### Logs Collection (لازم تتبنى منفصلة)
- حاجة **بتحصل** في لحظة معينة
- بتتسجل وخلاص — مفيش status
- مناسبة لـ: التمرين، الأكل، الوزن
- **متحطهاش جوا Tasks أبداً**

## البنية المعمارية المقترحة للمستقبل

```
Firestore
├── clients/{id}/projects/{id}/tasks/{id}   ← شغل وأهداف ✅ موجود
├── finance/                                 ← مصاريف ✅ موجود
├── logs/
│   ├── workout/{date}                       ← تمرين
│   ├── nutrition/{date}                     ← أكل
│   └── weight/{date}                        ← وزن
└── focusSessions/                           ← بومودورو ✅ موجود
```
