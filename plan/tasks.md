# 🚀 الإصدار v21.0 — إصلاح تداخل تكسير واجهة المشاريع أثناء السحب (Drag & Drop Layout Overflow Fix)

تستهدف هذه الخطة علاج المشكلة البصرية والبرمجية حيث يحدث تداخل (Overflow) وتشويه لهيكل كروت المشاريع الكبيرة أثناء إعادة ترتيبها أفقياً.

---

## 🎨 1️⃣ معالجة الـ CSS والـ DOM أثناء عملية السحب (Drag Layout Alignment)

### أ. تحجيم عنصر الـ Placeholder والـ Ghost Element
* **المشكلة:** عند سحب الكارت الكافي للمشروع، العنصر الوهمي البديل (Placeholder) والعنصر المسحوب لا يلتزمان بالـ Width أو الـ Box-sizing الفعلي، مما يتسبب في حشر الكروت وانزلاقها خارج الواجهة.
* **الحل الهندسي:**
  1. إجبار الـ Drag Container والـ Clone Element على تبني خاصية `box-sizing: border-box;` بشكل صارم.
  2. تثبيت خصائص الـ `flex-shrink: 0;` لعناصر المشاريع المجاورة لمنع انضغاطها أو كسر أبعادها الحادة أثناء حركة السحب.

### ب. منع الـ Overflow وإحكام الحاوية الأفقية (Horizontal Container Guard)
* تفعيل خاصية حظر التمدد العشوائي على الحاوية الأفقية الأم الكبرى عبر ضبط الـ Display ليكون متزناً (`display: flex;` مع `align-items: flex-start;`).
* قفل وتصفية خصائص الـ `z-index` لعنصر المشروع النشط (المسحوب حالياً) ليرتفع بسلاسة فوق الكروت الأخرى بدون تأثير على تموضعها الفيزيائي.

---

## 🛠️ 2️⃣ خطوات التنفيذ (V21.0 Action Items)

- [ ] **أولاً:** تتبع الكود البرمجي المسؤول عن مكتبة أو دالة السحب والإفلات (Drag and Drop) لكروت المشاريع والعملاء في واجهة التقويم.
- [ ] **ثانياً:** تعديل التنسيقات البرمجية المضافة ديناميكياً أثناء السحب (`dragging class` أو الـ `sortable-placeholder`) وتثبيت أبعاد العرض والارتفاع لها لتطابق الكروت الأصلية تماماً.
- [ ] **ثالثاً:** إصلاح أزمة تراكب النصوص والعناصر بإضافة `overflow: hidden;` مؤقت على الكروت أثناء السحب، وضمان عودة الـ Layout لوضعه المستقر بمجرد الإفلات (Drop).

# 🚀 الإصدار v22.0 — توسيع الهيدر العلوى وإظهار ساعات المشاريع الخارجية (Header Flex Fix & Project Card Hours Extension)

تستهدف هذه الخطة إنهاء انقسام زر إضافة المهمة، والتخلص نهائياً من عداد الساعات الدائري القديم، مع إضافة قراءة الوقت الإجمالي مباشرة على كروت المشاريع الخارجية.

---

## 🎨 1️⃣ إصلاح انقسام زر الهيدر وحذف العداد القديم (UI Layout & Element Cleanup)

### أ. فك ضغط زر "مهمة جديدة" (Flexbox Wrap Fix)
* **المشكلة:** ينقسم نص الزرار على سطرين بشكل مشوه نتيجة حشر الـ Flex Container أو إعطاء الـ `project-hours-gauge` مساحة عرض كبيرة على حساب الزر.
* **الحل الهندسي:**
  1. إجبار الزر على البقاء في سطر واحد باستخدام `white-space: nowrap;` ومنع انكماشه بـ `flex-shrink: 0;`.
  2. استغلال البراح الأفقي المتاح وإعادة توزيع المساحات (تعديل الـ `max-width` لشريط الساعات أو الـ `gap`).

### ب. الحذف النهائي لعداد الساعات القديم
* يتم تصفية وإزالة الدائرة الخضراء ومؤشرات "عمل / راحة" تماماً من كود واجهة التتبع، والاعتماد كلياً على الشريط الخطي النحيف المدمج في الهيدر.

---

## 📊 2️⃣ إظهار الساعات على بلوك المشروع الخارجي (Project Card Hours Gauge)

### أ. عرض الوقت على الكروت الخارجية (External Project Level UI)
* قبل الدخول إلى صفحة التاسكات الداخلية، يحتاج المستخدم لمتابعة إنتاجيته بمجرد النظر لكروت المشاريع الرئيسية.
* إضافة تاغ نصي صغير وأنيق في زاوية أو أسفل **بلوك/كارت المشروع الخارجي** يقرأ مباشرة قيمة حقل `totalProjectHours` من Firestore.
* **صيغة العرض النظيفة (Format):** تحويل الساعات الكسرية لعرضها بشكل محترف: `3h 40m` أو `1h 20m` بنفس ستايل خطوط ثيم PhpStorm الداكن.
