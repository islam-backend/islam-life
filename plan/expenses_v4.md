# 🚀 خطة التحديث v27.0 — نظام التتبع المالي بالشهور، وضع الخصوصية الافتراضي، وإعادة ترتيب البلوكات

تستهدف هذه الخطة إصلاح حسابات المصاريف التراكمية وعزلها شهرياً لمنع أخطاء تجاوز الميزانية الظاهرة في image_a3c2bc.png، مع دمج زر العين لحماية البيانات بصرياً بشكل افتراضي، وتفعيل ميزة السحب وإعادة الترتيب لكافة البلوكات.

## 🧠 1️⃣ معمارية الحسابات والفلترة الزمنية (Time-Based Financial Logic)

### أ. عزل الحسابات التراكمية (Monthly Scope Isolation)
* **الفصل الزمني الصارم:** يتم احتساب وجلب المؤشرات المالية بناءً على **الشهر والسنة المحددين حالياً في الواجهة** فقط.
* **منع التداخل:** عند تسجيل أي مصروف وتحديد تاريخه، يتم ربطه وحسابه ضمن وعاء الدخل التابع لنفس الشهر، ولا يتم ترحيل أو خصم مصاريف الشهور السابقة من دخل الشهر الحالي نهائياً لحل المشكلة المعروضة في image_a3c2bc.png.
* **معادلة المتبقي الصافي:** $$\text{المتبقي الصافي للشهر الحالي} = \text{إجمالي دخل هذا الشهر فقط} - \text{إجمالي مصاريف هذا الشهر فقط}$$

## 👁️ 2️⃣ وضع حماية الخصوصية الافتراضي (Default Hidden Privacy Mode)

### أ. السلوك الافتراضي عند التحميل (Hidden by Default)
* **الحماية الفورية:** بمجرد فتح الشاشة أو عمل Reload، تكون حالة الخصوصية مفعلة تلقائياً كخيار افتراضي `isPrivacyActive = true`.
* **تأثير التعمية البصري:** يتم تطبيق تأثير ضبابي ناعم `filter: blur(6px);` أو استبدال الأرقام بنقاط مشفرة `•••••` على كافة الحقول والكروت الحساسة التابعة لكلاس `.privacy-sensitive` (مثل كروت الدخل والصرف والمتبقي الصافي).

### ب. متحكم العين العلوي (Eye Toggle Switch)
* يتم إضافة أيقونة عين ناعمة حادة الحواف في الهيدر العلوي بجانب المؤشرات.
* عند الضغط عليها، يتم تبديل الحالة لإظهار الأرقام الحقيقية، مع حفظ التفضيل الحالي صامتاً في الـ `localStorage` لحفظ استقرار التصفح.

## 🕹️ 3️⃣ هندسة السحب وإعادة ترتيب البلوكات (Drag & Drop Layout Components)

### أ. ديناميكية ترتيب الحاويات الكبرى (Blocks Grid Reordering)
* يتم تمكين خاصية السحب والإفلات (Drag and Drop) على مستوى البلوكات الخارجية والداخلية للشاشة:
  - **بلوكات المشاريع والعملاء الخارجيين.**
  - **بلوكات وصناديق الصرف الديناميكية (Budget Buckets).**
* **ثبات الـ Layout:** عند سحب وإعادة ترتيب أي بلوك، يلتزم العنصر المسحوب والـ Placeholder بأبعاد الـ CSS الصارمة `box-sizing: border-box;` لمنع أي تداخل (Overflow) أو تكسير في محاذاة الكروت المجاورة.
* **حفظ الترتيب:** يتم تخزين مصفوفة الترتيب الجديد (`orderIndex`) في الـ Firestore لكل بلوك لضمان ثبات الترتيب المخصص عند فتح النظام من أي جهاز.

## 🛠️ 4️⃣ خطوات التنفيذ المحددة (Action Items لـ Claude)

- [ ] **أولاً (الفلترة الزمنية):** تعديل دالة الاستعلام (`onSnapshot`) في Firestore لتقوم بعمل فلاتر زرقاء (`where`) على حقل التاريخ بناءً على الشهر والسنة المحددين من شريط اختيار الشهور العلوي الجديد.
- [ ] **ثانياً (تفعيل الخصوصية الافتراضية):** برمجة الـ State البدئي لـ `isPrivacyActive` ليكون `true` دائماً عند تحميل الصفحة، وتغليف كافة الأرقام المالية المالية بكلاس الخصوصية.
- [ ] **ثالثاً (أيقونة التحكم):** بناء زر العين في الهيدر المالي وربطه بدالة التبديل وإضافة الـ CSS Blur اللازم صامتاً.
- [ ] **رابعاً (برمجة الـ Drag & Drop):** دمج دالة السحب لكروت المشاريع والعملاء والصناديق، وضمان مرونة حركة الكروت أفقياً وعمودياً بدون إحداث تشويه للـ UI مع رفع الـ `z-index` للكارت النشط أثناء السحب.
