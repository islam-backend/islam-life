[🎯 الفلسفة والهدف]:
تجميع كافة مصادر دخلك (رواتب الشركات + ميزانيات المشاريع الحرة) وموازنتها ضد مصاريفك (التزامات، تجهيز الفرح، ترفيه، يوميات) لتعطيك الشاشة رقم واحد وصريح: "كم متاح معك الآن؟" و"كم صرفت على الفرح حتى الآن؟".

--------------------------------------------------------------------------------
1️⃣ هيكل الإيرادات ومصادر الدخل (Multi-Source Income Architecture)
--------------------------------------------------------------------------------
بدل ما نعتمد على المشاريع فقط، كولكشن الدخل سيتعرف على نوعين من الإيرادات:

أ. الدخل الثابت المستمر (Fixed Salaries):
   - بند لـ (الشركة أ) وبند لـ (الشركة ب) ينزل تلقائياً أول كل شهر بقيمة الراتب الثابتة.

ب. الدخل المتغير (Freelance Projects):
   - يسحب الساعات من حقل `totalProjectHours` المعتمد في المشروع، ويضربها في سعر ساعتك ليحسب لك دخل المشروع الحر فوراً.

--------------------------------------------------------------------------------
2️⃣ تصنيف وتقسيم المصاريف الذكي (Smart Expense Categories)
--------------------------------------------------------------------------------
عند تسجيل أي مصروف بـ (القيمة والتاريخ)، ستختار له "فئة" (Category) محددة من قائمة منسدلة حادة مجهزة مسبقاً، وهي:

1. [ 🏠 التزامات ثابتة ]  -> (إيجار، فواتير كهرباء/إنترنت، اشتراكات برمجية).
2. [ 👰 تجهيزات الفرح ]  -> (بند منفصل تماماً لتجميع كل مليم يذهب لشقة الزوجية أو الحجز).
3. [ 🍔 مصاريف معيشية ]  -> (أكل، مواصلات، طلبات يومية).
4. [ 🧠 ترفيه وتفريح ]   -> (خروجات، مكافأة نفسك بعد شغل ضغط، شراء ألعاب أو أدوات).
5. [ 🛠️ ميزانية مشروع ]   -> (سيرفرات أو أدوات مدفوعة تشتريها مخصوص لمشروع عميل).

--------------------------------------------------------------------------------
3️⃣ التوزيع البصري عالي الكثافة (Financial UI Layout)
--------------------------------------------------------------------------------

أ. لوحة المؤشرات العلوية (Financial Micro-Cards):
   * 4 كروت رقمية نحيفة متراصة أفقياً بخط PhpStorm وثبات أبعاد تام:
     1. [ إجمالي الدخل المتاح ]  -> (رواتب الشركات + كاش المشاريع المكتملة).
     2. [ وحش الفرح (Total Joy) ] -> (عداد تراكمي يقول لك بالملي صرفت كام على الفرح لحد دلوقتي).
     3. [ الالتزامات الصامدة ] -> (مجموع الإيجار والمصاريف الثابتة لهذا الشهر).
     4. [ المتبقي الصافي ]      -> (رقم نهائي أخضر: الدخل مطروحاً منه كل المصاريف).

ب. شريط التوزيع النحيف (Budget Progress Bars):
   * أسفل المؤشرات، خطوط خطية نحيفة جداً (تدرجات ألوان مختلفة):
     - خط لـ [الفرح]، خط لـ [الالتزامات]، خط لـ [ترفيه نفسك]. لو خط الترفيه بدأ يملأ لآخره، السيستم يعطيك تلميح بصري خافت لتكبح الصرف قليلاً.

ج. خلاصة المعاملات السريعة (High-Density Transaction Rows):
   * صفوف مدمجة متراصة أفقياً لعرض المصاريف الأخيرة مع ميزة الحذف الفوري وصمت الـ Reload:
     - [أيقونة الفئة] | [العنوان: مثلاً دفعة حجز القاعة] ---> [القيمة: $$] (x)
     - [أيقونة الترفيه] | [العنوان: خروجة الويكيند] ---------> [القيمة: $$] (x)
